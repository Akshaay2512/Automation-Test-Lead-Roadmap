# Variables in Python

## What is a Variable?
A variable is a container used to store data.

Example:
name = "Akshaay"

## Rules
- Must start with a letter or _
- Cannot start with a number
- Case-sensitive

## Naming Convention
student_name
employee_salary

## Multiple Assignment
a, b = 10, 20

## Dynamic Typing
x = 10
x = "Python"
