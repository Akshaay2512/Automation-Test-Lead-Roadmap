# Python Variable Interview Questions

Q1. What is a variable?
A variable stores data.

Q2. Is Python statically typed?
No, Python is dynamically typed.

Q3. What is dynamic typing?
The type of a variable can change during execution.

Q4. What is the difference between = and == ?
= is assignment.
== is comparison.
