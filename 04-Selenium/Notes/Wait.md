Wait commands:

1. Implicit wait
2. explicit wait

**time.sleep(4)**
adv:
1. Simple to use

disadv:
1. performance of script is very poor
2. if element is not available within the time mentioned, still chance of getting exception

**Implicit wait**
adv:
1.single statement for whole program
2. performance will not be reduced

disadv:
1. still if element if not loaded in given second will throw exception

**Explicit wait**

explicit wait works based on the condition
